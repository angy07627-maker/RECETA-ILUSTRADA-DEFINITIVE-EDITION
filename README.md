# RecetaIlustrada

Tablón comunitario de recetas accesibles e ilustradas, enfocado en el ODS 2: Hambre Cero.

## Archivos
- `index.html`: estructura de la página.
- `style.css`: diseño y estilos visuales.
- `script.js`: funciones e interacciones.
- `README.md`: descripción del proyecto.

## Cómo probarlo
Abre `index.html` en tu navegador. Los datos de las recetas se guardan en el almacenamiento local del navegador, por lo que no se sincronizan entre dispositivos ni usuarios.

## Publicarlo con GitHub Pages
Sube estos cuatro archivos a la raíz del repositorio. Después, en GitHub ve a **Settings → Pages**, elige la rama principal (`main`) y la carpeta raíz (`/root`), y guarda los cambios.
